# ⚡ QUICK START — 5 Minutes to Running Portfolio

**The fastest way to get your portfolio running locally!**

---

## 🚀 In 5 Steps

### **Step 1: Extract (30 seconds)**
```bash
unzip hemraj-portfolio-frontend.zip
cd hemraj-portfolio-frontend
```

### **Step 2: Install (2 minutes)**
```bash
npm install
```

### **Step 3: Run (10 seconds)**
```bash
npm run dev
```

### **Step 4: Open Browser (5 seconds)**
Visit: **http://localhost:3000**

### **Step 5: Customize (1 minute)**
Edit `src/constants/metadata.ts`:
- Change your name
- Change your email

**Done!** Your portfolio is running! 🎉

## 🎨 Customize in 2 Minutes

### **Your Name & Email**
Edit: `src/constants/metadata.ts`

### **Your Intro Text**
Edit: `src/components/sections/Hero.tsx`

### **Your Skills**
Edit: `src/components/sections/Skills.tsx`

### **Your Projects**
Edit: `src/components/sections/Projects.tsx`

### **Your Colors**
Edit: `src/app/globals.css`
Change `--cyber` and `--teal`

## ✅ Next: Deploy (10 Minutes)

1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repo
4. Click Deploy
5. Done! Your site is live

## 🆘 Stuck?

| Issue | Solution |
|-------|----------|
| Port 3000 in use | Run: `npm run dev -- -p 3001` |
| Modules not found | Run: `npm install` again |
| Changes not showing | Clear cache: `rm -rf .next && npm run dev` |
| More help | Read: `FAQ.md` |
